# Fiber Tracer TUI

A terminal UI for Fiber Tracer built with [Bun](https://bun.sh/), [Ink](https://github.com/vadimdemedes/ink), and TypeScript.

## Usage

```bash
cd tui
bun install
bun run dev        # Run in development mode
bun run build      # Bundle to dist/
bun run typecheck  # Run TypeScript checks
bun run test       # Run tests
```

Press `Ctrl+C` to exit the running TUI.
